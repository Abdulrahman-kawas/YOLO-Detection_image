# YOLO-Detection_image
Object detection using YOLO with bounding box processing, confidence filtering, and image visualization in Python.

This project implements an object detection workflow using YOLO.
It focuses on handling detection results, processing bounding boxes,
filtering detections by confidence, and visualizing outputs on images.

The emphasis is on understanding the detection pipeline and image processing logic
rather than model training or AI theory.

## Features
- Object detection inference using YOLO
- Bounding box coordinate handling (xyxy)
- Confidence-based filtering
- Label and bounding box visualization
- Compatible with Google Colab

## Tech Stack
- Python
- YOLO (Ultralytics)
- OpenCV
- NumPy
- PIL
